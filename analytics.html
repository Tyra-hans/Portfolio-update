One-time setup needed to load live data

To connect this dashboard to your GA4 property, you need a Google OAuth Client ID. Follow these steps once, then click "Connect Google Analytics" above.

  1. Go to console.cloud.google.com → create or select a project
  2. APIs & Services → Library → enable Google Analytics Data API
  3. APIs & Services → Credentials → Create OAuth 2.0 Client ID (Web application)
  4. Add your portfolio URL to Authorized JavaScript origins
  5. Copy the Client ID and paste it as the value of GOOGLE_CLIENT_ID at the top of this file's script
